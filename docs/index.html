Features

它能做什么

为长文准备的写作流水线，不是一个单纯的预览器。

✍️写作与排版

  • 语法高亮、行号、软换行、查找、撤销 / 重做
  • 写作 / 分栏 / 预览三视图（Ctrl+1/2/3）
  • 模板库、截图 Ctrl+V 自动入 assets/
  • YAML frontmatter 渲染为元数据卡片

🧪代码与校验

  • 约 200 种语法高亮，围栏右上角可搜索切语言
  • 手写别名（golang / shell）照样高亮
  • 代码校验：本地三档 Qwen2.5-Coder 离线跑，或走你的 AI 接口
  • 检测硬件推荐档位，所用引擎全程明示

🤖AI 辅助

  • AI 写作：任意 OpenAI 兼容接口，可拉模型列表
  • 询问 AI：多轮对话、可参考当前文稿
  • AI 一键排版：只调排版不动内容，先预览再替换、可撤销
  • 接口只存本机 config.json

🗂️整理与历史

  • 文件夹即工作区，文件树 / 大纲 / 拖拽打开
  • 历史版本：定时把文稿（含未保存修改）存为本地 Git 版本
  • 时间线预览任意一版，恢复后 Ctrl+S 才落盘
  • zip 备份、保存后自动 Git 同步

📡发布与分发

  • 公众号草稿 API（内联样式排版）
  • 博客园 MetaWeblog
  • 知乎 / 头条 / CSDN / 简书 / 掘金 富文本分发
  • 图床上传改写、外链自动转参考列表

📦本地优先

  • 文稿就是磁盘上的 .md，没有私有数据库
  • 没有账号、没有需要登录的同步服务
  • 密钥明文存本机，自定义斜杠命令只跑你信任的脚本
  • 换台电脑用任何编辑器都能接着写
Download

下载

全部按用户安装，Windows 两个包都无需管理员权限；.exe 与 .msi 二选一，不要同时安装。

平台安装包说明
Windows x64 下载 .exe（推荐） 安装向导：可选安装 / 数据 / 配置位置与桌面快捷方式
Windows x64 下载 .msi 静默 / 企业部署（msiexec /i … /qn）
macOS（Apple Silicon） 下载 .dmg 拖入 Applications；未公证，首次启动右键 → 打开
Linux x64 下载 .deb sudo apt install ./Inkdown-*.deb，自带启动器图标

安装包未做代码签名：SmartScreen 提示时点「更多信息 → 仍要运行」；macOS 首次启动请右键 → 打开。

Build from source

从源码构建

要求 Rust 1.92+（MSVC toolchain）、Visual Studio 2022 Build Tools、CMake 与 libclang。

# 克隆仓库
git clone https://github.com/ice-a/inkdown.git && cd inkdown
# 运行 / 打发布包
cargo run
cargo build --release

测试：cargo test。Linux 装 libclang-dev，macOS 用 Xcode Command Line Tools。
